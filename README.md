# Photography Website using Django 📸

This project is a photography portfolio website built using **Django**. It is designed to showcase photographs through galleries and pages with a clean and responsive UI.

The project demonstrates the integration of backend logic with frontend templates, static assets, and media handling in Django.

---

## 🚀 Features

- Photography portfolio layout
- Image galleries
- Django templates and views
- Static and media file handling
- Clean and responsive UI

---


---

## 🛠️ Tech Stack

- Python
- Django
- HTML
- CSS / SCSS
